# ⚡ Digital VLSI Design — Verilog

A growing collection of **Verilog HDL implementations and testbenches** for digital circuits, created while learning and practicing RTL design and VLSI fundamentals.

> 🚧 **Work in Progress:** This repository is actively being updated with new Verilog modules, testbenches, and digital circuits.

## 📌 About This Repository

This repository is used to document my progress in **digital design and Verilog HDL**.

Each design is accompanied by a testbench where applicable, allowing the functionality of the circuit to be verified through simulation.

The repository will continue to expand as I implement more combinational and sequential circuits.

## 📂 Current Implementations

| Circuit | Design | Testbench | Type |
|---------|--------|-----------|------|
| D Latch | `latch.v` | `latch_tb.v` | Sequential |
| D Flip-Flop | `FF.v` | `FF_tb.v` | Sequential |

More modules will be added as the project progresses.

## 🧪 Simulation

Each circuit can be tested using its corresponding testbench.

For example:

`FF.v` → `FF_tb.v`

`latch.v` → `latch_tb.v`

The testbenches apply different input conditions and display the resulting outputs to verify circuit behavior.
